# Pet Paradise 🐾

Pet Paradise is a full-stack Laravel e-commerce application designed for selling pet products in a scalable and production-ready architecture.

The platform includes:

- Secure authentication system
- Database-driven shopping cart (persistent cart per user)
- Product reviews with one-review-per-user validation
- User profile management with image upload
- Dynamic cart quantity updates
- Order-ready cart structure for future checkout integration
- Clean UI built with Tailwind CSS

The system follows Laravel best practices including:
- Eloquent relationships
- RESTful routing
- Middleware protection
- Clean controller architecture
- Session and database state management

Pet Paradise is built with scalability in mind, allowing easy extension to:
- Payment gateways
- Order management system
- Admin dashboard
- Inventory control
- Coupon/discount logic

Tech Stack:
- Laravel
- MySQL
- Tailwind CSS
- Blade
